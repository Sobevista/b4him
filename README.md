# b4him

The site behind **b4him.com**. Domain owned since before this repo; the site is being built in public, fumbling included.

## What this is

Ministry in the *purpose* sense, not the preachy one: **show the homework, invite others to play.** Teachings, exercises, the progression itself, and the actual work product — published free to download. The failures stay in the record alongside the wins, because the record is the point.

Beacon = lighthouse. Home-page mantras:

- **MBS** — Mind / Body / Spirit
- Progress over perfection
- 1% better every day
- Be intentional with your suffering
- Seek failure

## The scope trap, named up front

This is **three products** wearing one domain name, and building them together is how it dies:

1. a static content site
2. a video host
3. a comment system

Self-hosting video before anyone is watching is rent on an empty theater. So the ladder is deliberate:

| Tier | What ships | Gate to the next rung |
|---|---|---|
| **v0 — static** | mantras + resources catalogue as a browsable folder tree + games playable in-page | it exists, it looks right, someone lands on it |
| **v1 — embedded** | YouTube embeds (free player, free comments, and the cross-posting happens anyway) | traffic worth moderating |
| **v2 — owned** | own comment system / Patreon | — |

**v0 is the whole current scope.** v1 and v2 are written down so they stop being tempting, not because they are next.

## First resident

**DELIVERANCE** (arcade-progression rung 7) — ministry-aligned, standalone, one HTML file, embeds in-page with no build step. It is the natural first thing the site has to show.
